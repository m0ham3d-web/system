# Buying, Selling & Stock Management System

An Excel-based business management system designed to help small businesses organize their products, purchases, sales, and inventory in one structured workbook.

## Overview

This project provides a connected inventory and transaction tracking system built with Microsoft Excel formulas. It helps track stock movements, calculate sales and profit, monitor inventory levels, and review physical stock counts.

## Features

- **Product Management:** Maintain a product catalog with IDs, categories, units, cost prices, selling prices, suppliers, and reorder levels.
- **Purchase Tracking:** Record purchases, quantities, unit costs, suppliers, payment status, and purchase totals.
- **Sales Tracking:** Record sales, customers, quantities, selling prices, payment status, and automatically calculated profit.
- **Automatic Inventory Calculation:** Track stock based on recorded purchases and sales.
- **Stock Valuation:** Calculate the cost value of current inventory.
- **Low Stock Monitoring:** Identify products that have reached or fallen below their reorder levels.
- **Physical Stock Auditing:** Compare actual stock counts with system quantities and flag mismatches.
- **Dashboard:** View key business metrics, including total purchases, total sales, total profit, stock value, and products requiring reorder.
- **Getting Started Guide:** Includes an introductory sheet explaining the workbook and its color-coded input system.

## Workbook Structure

| Sheet | Purpose |
|---|---|
| Start Here | Instructions and workbook guide |
| Products | Product catalog and inventory status |
| Buying | Purchase transaction records |
| Selling | Sales transaction records |
| Stock Check | Physical inventory auditing |
| Dashboard | Business summary and reorder overview |

## Getting Started

1. Download `Buying_Selling_Stock_System.xlsx` from this repository.
2. Open the workbook using Microsoft Excel.
3. Start with the **Start Here** sheet.
4. Add or update your products in the **Products** sheet.
5. Record purchases in **Buying** and sales in **Selling**.
6. Review inventory and business metrics through **Stock Check** and **Dashboard**.

## Important Notes

- Yellow cells are intended for user input.
- Formula cells should not be overwritten.
- The workbook contains prepared transaction and product entry areas. Follow the instructions in the workbook before entering your own data.
- Use a spreadsheet application that supports Excel formulas for the best experience.

## Project Goal

The goal of this project is to provide a practical and organized Excel solution for managing everyday business operations, reducing manual calculations, and improving inventory visibility.
